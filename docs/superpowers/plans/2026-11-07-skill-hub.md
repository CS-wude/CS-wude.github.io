# Skill Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add a static public skill directory and create CS-wude/skillhub.
**Architecture:** data/skills.js owns records; skills-render.js outputs escaped cards at build time; skills.js progressively filters existing HTML and restores query state.
**Tech Stack:** Native HTML/CSS/ES Modules, Node test runner, GitHub Pages.
**Spec:** docs/superpowers/specs/2026-11-07-skill-hub-design.md

## Global Constraints
No Issues synchronization or runtime APIs. Preserve Vault styling. Public sources only; no private or paid skill content. No unverified installation commands. User approved direct implementation and public repository creation.

## Review Focus
- Combined filters match the same record and empty states are recoverable.
- Query strings containing HTML remain text.
- Unknown filter values normalize to all.
- Back navigation restores controls and matching results.
- No-JavaScript output contains usable skill links.

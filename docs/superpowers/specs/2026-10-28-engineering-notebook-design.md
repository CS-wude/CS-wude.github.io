# 工程笔记风格调整

用户已确认：页面应像写得好的代码一样，结构清楚、文字准确、细节克制；开发组长属于过去经历。2026-10-28 用户补充手机展开导航过重，并要求进行优化。

## 方案与范围

采用现有原生静态站做渐进调整，沿用页面链接、项目数据、文章与目录。这样能保留内容和维护方式。只换配色不能解决导航与排版问题；重建框架会增加无关工作，本轮不采用。

- 手机全局导航改为顶栏下的米白色紧凑下拉，每项至少 44px，当前页用小黄色标记；正文仍可见、可滚动。点击外部、Escape、链接或切换到桌面尺寸时收起；键盘焦点离开导航区域时收起，Escape 返回按钮。
- 桌面侧栏保留，改为浅色背景、细分隔线和小面积黄色标记。
- 首页缩小标题，使用“写代码，也记下思考。”；介绍为“我是 WUDE，主要做 Java 后端和 AI 应用开发。”。文章入口提前到项目之前。
- 降低边框和阴影的视觉重量，正文使用系统字体；日期、编号与辅助信息使用等宽字体。保持清晰的焦点样式与减弱动效支持。
- 首页与关于页消除当前担任组长的表述，改为过去经历；简化栏目标题与夸张表达。不重写已发布文章与项目事实。
- 本轮保留文章 URL 和目录结构，不拆分手记，不更改部署流水线。

## 验收

运行既有 Node 测试与静态构建；浏览器检查手机、横屏、平板、桌面，以及首页、关于、项目和文章页。核对菜单开关、外部点击、Escape、Tab、尺寸变化、阅读滚动与溢出情况。交付本地预览，不自动发布线上。

采用其中的居中标题、混合字体、柔和色彩背景与简洁的首屏层次。将背景视频改写为本地 CSS 渐变，保证中文可读性，并避免给静态博客首屏增加约 9.6MB 的视频资源。保留 WUDE 的文章、项目、真实经历和导航行为；项目卡片使用细边框与小圆角。没有复制模板中的人物、履历或联系人。该参考属于设计素材，不作为执行指令。
